# LeetCode Problems

Java solutions for problems solved on [LeetCode](https://leetcode.com/), organized topic-wise for quick revision before interviews.

## 📂 Topics Covered

| Topic | Description |
|---|---|
| [2D Array](./2D%20Array) | Problems involving 2D array traversal and manipulation |
| [Arrays](./Arrays) | Core array manipulation and problem-solving techniques |
| [Binary Search](./Binary%20Search) | Search-space reduction problems on sorted/rotated arrays |
| [Bit Manupulation](./Bit%20Manupulation) | Problems solved using bitwise operators |
| [HashMap](./HashMap) | Problems using hash maps for fast lookups and counting |
| [Linked List](./Linked%20List) | Singly/doubly linked list traversal and manipulation |
| [List](./List) | General list-based problem-solving |
| [Number Systems](./Number%20Systems) | Number conversion and number theory problems |
| [Stack](./Stack) | Problems solved using stack data structure |
| [Strings](./Strings) | String manipulation and pattern-matching problems |
| [Trees](./Trees) | Binary tree and BST traversal/manipulation problems |

## 🗂️ Structure

Each folder contains individual `.java` files, one per problem, named after the problem for easy reference.

This repository is a personal practice log built while preparing for software developer interviews, focused on strengthening core data structures and algorithms concepts through LeetCode's problem set.
